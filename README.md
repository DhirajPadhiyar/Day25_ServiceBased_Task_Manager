# Day 25 - Service Based Task Manager

## Project Overview

A professional ASP.NET Core MVC application demonstrating Service Layer architecture with Dependency Injection, Entity Framework Core, SQL Server, CRUD operations, Validation, and xUnit Unit Testing.

## Features

- Create Task
- View Tasks
- Update Task
- Delete Task
- Dependency Injection
- Service Layer
- Entity Framework Core
- SQL Server
- Data Validation
- xUnit Unit Testing
- InMemory Database Testing

## Technologies

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap
- xUnit
- Moq
- Git & GitHub
